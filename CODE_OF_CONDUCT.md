# Code of conduct

Be kind and patient. Talk about the code and the idea, not the person. No harassment, insults or
personal attacks, and never share someone's private information.

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
It applies to issues, pull requests, discussions and any other place where the project is
represented.

## Reporting

Report a problem to support@cavnfox.com. Reports are kept private. The maintainer reads every
one and may edit or remove comments, or block people who keep breaking these rules.
