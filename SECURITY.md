# Security

## Report a problem privately

Please do not open a public issue for a security problem. Report it in one of these ways:

- On GitHub: open the Security tab of https://github.com/NotCavnfox/holyarrs-discord and click
  "Report a vulnerability".
- By email: support@cavnfox.com

Say what you found, how to reproduce it, the plugin version and your HolyArrs version.

You get an answer within 7 days and updates while it is being fixed. When the fix ships, you are
credited in the release notes unless you ask not to be.

## Never post a token

Do not put a Discord bot token, a link code or any other secret in an issue, a pull request, a
log paste or an email. They are not needed to look into a report. If a token did get posted,
reset it right away on the Bot tab at discord.com/developers.

## Supported versions

Only the latest release gets security fixes. Please update before you report.

## Problems in HolyArrs itself

A problem in the sandbox or in HolyArrs, not in this plugin, goes to
[HolyArrs](https://github.com/HolyArrs/HolyArrs/security/policy).
